1. Pendahuluan

Platform AgriMRV by Save Subak memanfaatkan teknologi penginderaan jauh (remote sensing) terkini untuk melakukan Measurement, Reporting, and Verification (MRV) pada lahan pertanian sawah. Dokumen ini merangkum metodologi ilmiah yang kami gunakan, memastikan transparansi penuh bagi auditor karbon maupun pemangku kepentingan kelestarian lingkungan.

2. Spesifikasi Satelit Pemantau

Untuk memastikan keandalan data dalam segala kondisi cuaca, AgriMRV menggunakan pendekatan multi-sensor dari konstelasi satelit Copernicus milik European Space Agency (ESA).

A. Sentinel-2 (Satelit Optik Multispektral)

  • Fungsi: Bertindak sebagai "Kamera Raksasa" yang menangkap pantulan cahaya matahari (kasat mata maupun inframerah) dari permukaan bumi.
  • Keunggulan: Resolusi spasial hingga 10 meter, sangat tajam untuk memetakan petak-petak sawah.
  • Interval Pengambilan: Melewati lokasi yang sama setiap 5 hari sekali, memberikan data time-series yang sangat padat secara gratis.

B. Sentinel-1 (Satelit Radar / SAR)

  • Fungsi: Menggunakan teknologi Synthetic Aperture Radar (SAR) yang memancarkan gelombang mikro secara mandiri ke bumi dan menangkap gemanya.
  • Keunggulan Utama: Mampu menembus awan tebal dan hujan, serta beroperasi di malam hari. Digunakan untuk mengukur struktur fisik tanaman dan kelembapan tanah permukaan (VV & VH).

3. Anatomi Algoritma Satelit: Tujuan, Korelasi Karbon & Analogi

Bagian ini membedah kelima parameter satelit yang digunakan oleh sistem AgriMRV. Setiap parameter tidak hanya diukur secara matematis, namun memiliki korelasi langsung dengan praktik pertanian organik dan kalkulasi emisi karbon.

3.1. NDVI (Normalized Difference Vegetation Index)

Rumus Satelit: (NIR - Red) / (NIR + Red)

  • Tujuan Utama: Mengukur tingkat kesehatan, kerapatan kanopi, dan laju pertumbuhan biomassa padi.
  • Korelasi Pertanian Organik: Menjadi bukti empiris bahwa pupuk kompos/organik (tanpa pupuk kimia sintesis) berhasil memberikan nutrisi optimal. Kurva NDVI yang terus menanjak membuktikan tanah organik mampu menopang pertumbuhan tanaman dengan sempurna.
  • Korelasi Kredit Karbon: Semakin tinggi biomassa (daun lebat hijau), semakin besar proses fotosintesis. Fotosintesis secara harfiah menyedot CO2 dari atmosfer dan menyimpannya di dalam jaringan tubuh tanaman (Carbon Sequestration). NDVI tinggi = Serapan Karbon Tinggi.
Analogi: "Burger Merah dan Batu Panas"
Matahari melempar cahaya Merah (Red) dan Inframerah (NIR/Batu Panas). Daun padi sehat melahap habis si Merah sebagai makanan, dan menendang jauh-jauh Batu Panas karena berbahaya. Satelit menghitung: (Tinggi - Nol) / (Tinggi + Nol). Hasilnya Positif Tinggi (+1). Sebaliknya, tanah kosong tidak bisa makan cahaya merah, sehingga nilainya menjadi Negatif.

3.2. NDWI (Deteksi Genangan Optik)

Rumus Satelit (McFeeters): (Green - NIR) / (Green + NIR)

  • Tujuan Utama: Membedakan area genangan air dengan kondisi lahan kering di sawah secara presisi tinggi, khusus di saat langit sedang cerah.
  • Korelasi Pertanian Organik: Memastikan kepatuhan jadwal irigasi dari tata kelola Subak tradisional.
  • Korelasi Kredit Karbon: Kunci emisi sawah ada pada genangan air. Sawah yang terus-menerus tergenang akan menghasilkan bakteri anaerobik (tanpa oksigen) yang melepaskan Gas Metana (CH4).
  • Dukungan Deteksi AWD (Bila Cuaca Cerah): Jika langit cerah, NDWI membantu radar memverifikasi praktik pengeringan lahan (AWD) lewat grafik yang ber-zig-zag (positif ke negatif). Namun, karena di Indonesia musim tanam berbarengan dengan awan hujan pekat, tugas utama verifikasi AWD diserahkan pada satelit Radar VV.
Analogi: "Spons Raksasa Penelan Batu"
Air adalah musuh inframerah (NIR). Saat inframerah jatuh ke air, air menelannya tanpa sisa (Pantulan 0). Namun cahaya Hijau (Green) tetap memantul sedikit. Satelit menghitung (Hijau - Nol) / (Hijau + Nol) = Positif Terang. Namun, saat lahan dikeringkan untuk protokol AWD, tanah menendang inframerah kembali ke angkasa, mengubah hitungan menjadi Negatif Gelap. Kedipan "Terang-Gelap" di satelit inilah bukti valid keberhasilan AWD.

3.3. NBR (Normalized Burn Ratio)

Rumus Satelit: (NIR - SWIR) / (NIR + SWIR)

  • Tujuan Utama: Bertindak sebagai "Detektor Kebohongan" pasca-panen untuk memastikan tidak ada jerami padi yang dibakar.
  • Korelasi Pertanian Organik: Sisa jerami panen wajib dibiarkan membusuk atau dibajak kembali ke tanah sebagai kompos alami penyubur hara. Pembakaran akan menghancurkan siklus nutrisi organik ini.
  • Korelasi Kredit Karbon: Membakar jerami langsung melepaskan Black Carbon (karbon hitam) dan CO2 pekat ke udara (Emisi Masif). Sistem menggaransi status Zero Burn (Nol Pembakaran) sebagai syarat mutlak penerbitan kredit karbon. Pelanggaran berarti pembatalan kredit.
Analogi: "Sinar Oven Pencari Abu"
Sinar Oven (SWIR) sangat sensitif pada air tapi terserap oleh benda basah. Lahan panen yang normal masih menyimpan kelembapan alami, sehingga menyerap habis Sinar Oven (Nilai Positif). Jika lahan dibakar, arang dan abu yang kerontang (0% air) memantulkan Sinar Oven hingga menyilaukan satelit, menjadikan nilai anjlok ke Negatif Tajam.

3.4. Radar VV (Sensor Utama Verifikasi AWD Tembus Awan)

Rumus Satelit: Gelombang Mikro Aktif (Transmisi Vertikal, Penerimaan Vertikal)

  • Tujuan Utama: Menjadi tulang punggung (backbone) pendeteksi kekasaran tanah dan sensor utama verifikasi praktik AWD karena tidak bisa dihalangi oleh badai awan monsun sekalipun.
  • Korelasi Pertanian Organik: Memastikan tanah benar-benar dibajak sempurna agar pupuk kompos organik tercampur rata ke dalam lumpur.
  • Pembacaan Protokol AWD (Kuantifikasi Hari Aerasi): Inilah senjata utama kita untuk memenuhi standar ketat Verra VM0051. Saat sawah digenangi air, sinyal Radar VV terpantul menjauh (Nilai VV anjlok). Namun, saat petani membuang air untuk pengeringan berkala (AWD), permukaan tanah yang kasar kembali terekspos sehingga Radar memantul keras (Nilai VV meroket tajam).
    Sistem tidak hanya melihat grafiknya, tetapi secara otomatis menghitung durasi selisih hari antara grafik naik (mulai kering) dan grafik turun (mulai basah). Angka kuantitatif ini disebut sebagai "Total Hari Aerasi / Kering". Tanpa angka valid dari Radar VV ini, kita tidak bisa mencetak kredit karbon AWD di daerah tropis!
Analogi: "Lemparan Bola Tenis Lurus"
Radar bertindak seperti kelelawar. Satelit melempar "bola tenis" lurus tegak ke bumi. Jika lahan sedang digenangi air (licin seperti cermin), bola terpantul menjauh (Gema Hilang = VV Anjlok). Namun saat lahan sengaja dikeringkan untuk AWD, bola menabrak tanah kasar dan memantul lurus kembali ke atas (Gema Keras = VV Meroket). Grafik yang tiba-tiba meroket naik menceritakan kedisiplinan AWD petani tanpa satelit harus melihatnya secara visual.

3.5. Radar VH (Kepadatan Kanopi Tembus Awan)

Rumus Satelit: Gelombang Mikro Aktif (Transmisi Vertikal, Penerimaan Horizontal)

  • Tujuan Utama: Memindai volume struktur fisik kanopi tanaman dalam 3 Dimensi, benar-benar tak peduli jika cuaca sedang gelap atau badai berawan lebat.
  • Korelasi Pertanian Organik: Mengukur kepadatan batang dan kerimbunan tajuk daun padi. Ini membuktikan secara mekanis bahwa tanaman (walau tanpa bahan kimia sintesis) tumbuh memiliki postur yang sangat kokoh dan bervolume besar.
  • Korelasi Kredit Karbon: Saat siklus curah hujan tinggi (musim hujan), satelit optik (NDVI) menjadi "buta" karena awan. VH mengambil alih tugas pembuktian biomassa. Ini memvalidasi bahwa penyerapan CO2 oleh tanaman tidak pernah terhenti sedetik pun, sehingga perhitungan karbon tetap utuh dan diakui auditor global.
Analogi: "Lemparan Bola Tenis Putar"
Satelit melempar bola lurus, tapi bola menabrak "hutan" batang padi yang rimbun. Bola terjebak dan memantul-mantul rumit di dalam kanopi, lalu memantul balik ke angkasa dengan putaran menyamping (Horizontal). Semakin rimbun padi, semakin banyak "bola putar" yang kembali menabrak satelit (VH Tinggi).

5. Bukti Akurasi Sistem: Studi Kasus Fase Tanam

Untuk membuktikan bahwa rumus yang digunakan bekerja sempurna di lapangan, perhatikan grafik fluktuasi NDVI dan NDWI di area persawahan berikut:

Analisis Validasi (Mengapa Garis Bergerak Seperti Cermin?):
Grafik yang saling berkebalikan secara persis (simetris) antara NDVI (Hijau) dan NDWI (Biru) adalah bukti absolut akurasi sistem untuk lahan sawah padi:

  1. Fase Genangan (Awal Grafik - 26 Mei): Sawah dibajak dan dipenuhi air. Air menelan gelombang NIR, menyebabkan NDWI meroket tinggi. Karena belum ada daun, NDVI anjlok.
  2. Fase Vegetatif Rimbun (Tengah Grafik - 25 Jun): Padi tumbuh lebat menutupi air. Daun memantulkan NIR secara masif. Akibatnya, NDVI meroket tajam ke atas. Karena air tertutup kanopi, NDWI anjlok menjadi negatif.

Pola "cermin bersilangan" ini merupakan sidik jari unik dari siklus tanam padi yang sehat.

6. Metodologi Kalkulasi Kredit Karbon (Standar Global)

Setelah satelit (Optik & Radar) memverifikasi bahwa petani benar-benar menjalankan praktik organik dan AWD, sistem AgriMRV akan menghitung jumlah emisi gas rumah kaca yang berhasil dicegah. Kami merujuk pada metodologi standar global seperti UNFCCC CDM AMS-III.AU (Methane emission reduction by adjusted water management practice in rice cultivation).

Rumus Utama Pengurangan Emisi (Emission Reduction / ER):
ER = BE - PE - LE
  • BE (Baseline Emissions - Historis 3 Tahun / 36 Bulan): Emisi jika petani tidak bergabung dengan program (sawah digenangi terus-menerus). Syarat mutlak Verra VM0051 mewajibkan pembuktian kebiasaan petani sebelum proyek. Saat lahan baru didaftarkan, sistem akan menarik riwayat satelit 3 Tahun Penuh (1095 Hari) ke belakang sebagai bukti otentik kebiasaan lama (Baseline) petani (Continuous Flooding), lalu menyimpannya secara permanen.
  • PE (Project Emissions): Emisi riil saat ini setelah petani mematuhi protokol AWD. Sistem mengonversi "Total Hari Aerasi" dari Radar VV ke dalam tonase penurunan gas metana (CH4), lalu menetralkan (net) dengan kenaikan gas N2O yang menyertai praktik AWD. Rumus konversi menggunakan IPCC Tier 2: NET CO2e = (Hari Aerasi × 1.22 kg CH4/ha/hari × Luas Lahan Hektar × 27 GWP × 0.653 faktor netting N2O) / 1000.
  • LE (Leakage Emissions): Emisi kebocoran di luar area proyek (biasanya diasumsikan nol).

Kenapa Metana (CH4) sangat berharga?
Dalam ilmu iklim (Global Warming Potential / GWP), berdasarkan IPCC AR6 (2021), 1 Ton Gas Metana yang dicegah diperkirakan setara dengan mencegah lepasnya sekitar 27 Ton CO2 — angka ini kami netralkan lagi dengan faktor koreksi kenaikan N2O (0.653) supaya tidak overstate manfaat sesungguhnya. Estimasi ini didasarkan pada metodologi standar internasional, bukan pengukuran langsung di tiap lahan, dan menjadi dasar mengapa kombinasi verifikasi Radar VV (bukti AWD) dan NDVI (bukti biomassa organik) berpotensi menghasilkan kredit karbon berkualitas tinggi (High-Quality Carbon Credits).

7. Ground Truthing (Bukti Fisik Lapangan) & Hysteresis

Kelemahan sensor satelit Radar (yang rentan terhadap embun atau noise angin) diatasi AgriMRV melalui 2 lapis filtrasi:

  • Hysteresis Logika (Syarat 2 Titik): Status genangan lahan tidak akan berubah di sistem hanya karena anomali 1 hari. Status 'Kering' baru tervalidasi jika satelit secara konsisten melihat kondisi kering pada minimal 2 kali jadwal scan berturut-turut.
  • Pizometer (Pipa Pantau Air): Meskipun satelit mengumpulkan data raksasa dari luar angkasa secara Remote Sensing, AgriMRV tetap mewajibkan Ground Truthing. Petani harus memasang Pipa Paralon berlubang (Pizometer) di sawahnya dan menginput ketinggian air tanah sesungguhnya ke dalam aplikasi sebagai kalibrator manual terhadap tebakan satelit.

8. Lampiran Teknis: Algoritma & Kode JavaScript

Bagian ini disediakan khusus bagi auditor teknis (Konsep Whitebox) guna memverifikasi bahwa perhitungan indeks murni menggunakan rumus standar internasional.

/**
 * FUNGSI PERHITUNGAN INDEKS SATELIT (SENTINEL-2)
 * Platform: AgriMRV by Save Subak
 */

// 1. NDVI (Normalized Difference Vegetation Index)
export function calculateNDVI(nir, red) {
    if (nir + red === 0) return 0; // Mencegah error pembagian 0
    return (nir - red) / (nir + red);
}

// 2. NDWI (Normalized Difference Water Index) - Metode McFeeters
export function calculateNDWI(green, nir) {
    if (green + nir === 0) return 0;
    return (green - nir) / (green + nir);
}

// 3. NBR (Normalized Burn Ratio)
export function calculateNBR(nir, swir) {
    if (nir + swir === 0) return 0;
    return (nir - swir) / (nir + swir);
}

9. Komitmen Transparansi & Kolaborasi

Seluruh metodologi di atas adalah estimasi berbasis data satelit dan literatur ilmiah standar — bukan hasil pengukuran langsung di setiap lahan, dan belum menjalani audit karbon resmi.
